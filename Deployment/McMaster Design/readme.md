- 4/40 Hex Machine Nuts 
- 1/4 Flat Washers 
- 1/4-20 x 1" Socket Cap Screw
- 1/4-20 x 3" Socket Cap Screw

**Instructions:**
1. Knockout a knockout of the polycase on the opposite side of the water level sensor. This deployment part will attach to the top of the polycase with the water level sensor pointing perpendicular to water. 
2. Attach the DIN Rail to the strut channel bracket using a 1/4-29 x 1" screw, washers, and nut. Note that we want the solar panel at a 30 degree angle, so attach these two parts appropriately (see photo).
3. Attach the solar panel to the DIN rail using 4/40 x 3/4" screws, nuts, and washers.
<img width="280" height="319" alt="image" src="https://github.com/user-attachments/assets/a3b2dfdf-615c-4bce-9ed2-6189e415adf0" />

4. Line up the holes from the new knockout, strut channel with mounting plate, and struct channel bracket so that the DIN rail with panel hang over the polycase like a hood. Use the 1/4-20 x 3" screws with nuts and washers to attach all 3 parts together.
<img width="280" height="255" alt="image" src="https://github.com/user-attachments/assets/cb27e312-4eb1-41dc-a288-b84bc957581e" />

**Notes:** 
- In the photo I did not use a separate knockout to test this product, I was using the knockout orginally for the water level sensor just to see if this design was practical. In your version you should have 3 knockouts in total. One for the water level sensor, one for the deployment attachment, and one for the solar cable to run through with a cable gland.
- Some sort of sealant may be necessary in the final deployment product around the deployment designated knockout. Try to make the washers line up perfectly with the hole so that it acts as a natural seal too.
